# Tkinter 键位编辑器

需要 Python 3.10 或更新版本以及 Tkinter。当前电脑的 Python 3.12 已包含 Tkinter。
仅使用 Python 标准库，无需 pip 安装，也无需编译。

双击本目录的 `start.bat`，或在本目录执行：

```powershell
python keyboard_config.py
```

默认读取 `Keyboard-Config/keymap.c`，路径相对于程序目录确定，不受终端工作目录影响。
也可以点击“打开文件”，或者使用 `python keyboard_config.py --keymap 路径`。
键值候选项从配套的 `keymap.h` 读取，支持 `.c` 和 `.h` 放在不同目录。
自动查找顺序为 C 文件同目录、上一级目录中的 `inc/keymap.h`、`include/keymap.h`，
例如打开 `Lib/src/keymap.c` 会自动找到 `Lib/inc/keymap.h`。
找不到时会弹出文件选择框，让你手动选择头文件；取消后保留原来的配置。

顶部显示实际使用的源文件和头文件路径，也可点击“选择头文件…”手动更换。
更换头文件只刷新候选功能，不丢弃尚未保存的键位修改。
每个 C 文件选定的头文件路径会在本次运行中记住，重新加载时优先复用并重新读取；重启后重新查找。
宏编辑器也会复用主窗口选定的头文件，打开其他宏文件时支持相同的自动查找和手动选择流程。
头文件只读取，不会被编辑器覆盖；没有可用键值或读取失败时保留原来的配置。

## 操作

1. 在顶部选择普通层或 Fn 层。
2. 点击键盘上的物理按键。圆形旋钮位于右方向键上方、上方向键右侧，下标为 84。
3. 在右侧搜索功能名称或 C 常量，选中功能，再点击“应用到按键”。双击功能也可应用。
4. 点击“保存到 keymap.c”或按 Ctrl+S，写回当前打开的文件。Ctrl+Z 撤销尚未保存的编辑操作。

蓝色表示选中，黄色表示相对已加载文件有修改，浅绿色表示 Fn 层与普通层不同。
键帽小字表示固定物理位置；大字表示当前配置的功能。

Fn 的识别由两层共同决定：将 Fn 设置到新位置时，会与原 Fn 位置交换两层键值。
将原 Fn 改成普通功能时，会同时修改两层。移除所有 Fn 时保存会提示。

## 旋钮旋转

键盘下方提供“按压 / 顺时针 ↻ / 逆时针 ↺”三个按钮，显示当前层各自的功能。
先选普通层或 Fn 层，再点击旋转方向，在右侧选择功能并应用、保存即可。
两个方向、两个层独立配置；按钮上的 `*` 表示该项尚未保存。

- 旋钮按压仍对应物理键下标 84，支持普通按键可用的全部功能。
- 旋转映射读取、写回同一个 `keymap.c` 内的 `knob_map`。
- 按当前固件约定，旋转仅支持头文件中的 `CONSUMER_*` 媒体功能以及 `KBD_KEY_NONE`（禁用）。
  编辑旋转时，候选列表自动过滤掉普通按键、修饰键和 Fn/配对等内部动作。
- 例如普通层保持音量增减，Fn 层设为下一曲 / 上一曲。
- 旋转修改与普通改键共用 Ctrl+Z、未保存提示、备份和外部修改保护。
- 支持当前 `[0]` / `[1]` 层及 `[KBD_KNOB_CW]` / `[KBD_KNOB_CCW]` 方向的显式初始化，
  顺序可以调整；缺项、重复定义或不支持的表达式会报错，不会写入文件。
- 旧文件没有 `knob_map` 时仍可改普通按键，两个旋转按钮显示“未配置”并禁用。

## 宏触发键与动作编辑

普通按键和旋钮按压可以在“宏”分类选择 `KBD_KEY_MACRO_0`～`KBD_KEY_MACRO_3`，
以及 `KBD_KEY_MACRO_CANCEL`。旋转方向仍只支持媒体功能或禁用。
默认 Fn+F6 触发宏 0，Fn+F7 取消；普通层 F6/F7 保留。

点击顶部“宏编辑器…”打开动作配置，默认读取当前 `keymap.c` 同目录的 `macro_config.c`。
本项目已从 `Lib/src/macro_config.c` 建立 `Keyboard-Config/macro_config.c` 副本，初始序列保持一致。
文件不存在时会让你选择宏文件；打开后完整路径始终显示在窗口顶部。
如果主窗口选中的键已经绑定宏 0～3，宏编辑器会直接显示对应槽位。

1. 选择宏槽位 0～3。未配置的槽位显示“不执行”，添加动作并保存后会自动生成帧数组和槽位引用。
2. 点击“新增帧”或双击现有帧，设置名义时间（毫秒）以及此时应保持按住的完整键集合。
   最多选择 8 键，包含普通键及左右 Ctrl / Shift / Alt / Win；选“（无）”表示不使用该项。
3. 点击“应用此帧”。帧按时间排序；同一时刻的多键放在同一帧，时间重复会报错。
4. 用“末尾添加释放”追加一个空帧（默认间隔 80 ms，可双击调整）。保存时要求最后一帧释放所有键。
5. 点击“保存 macro_config.c”。然后回主窗口配置触发键并保存 `keymap.c`。

例如 Ctrl+C 可以使用：`0 ms: 左 Ctrl + C` → `80 ms: 释放所有键`。
需要重叠按住时，继续在后续帧中列出保持的键，例如 `A` → `A+B` → `B` → `空`。
表格同时显示名义时间、间隔、完整持有键和相对上一帧的变化。

- 每个宏最多 128 帧；时间范围 0～4294967295 ms，第一帧可以非零。
- 宏中不允许媒体键、Fn、配对、宏触发等内部功能，也不支持文本输入、鼠标或录制。
- “复制帧”可快速追加相同状态；“清空此宏”禁用该槽位，不修改物理触发键。
- 宏窗口独立保存和撤销（Ctrl+S / Ctrl+Z），切换槽位保留修改；关闭有未保存内容时会提示。
- 每次保存都有时间戳备份，检测到外部修改时拒绝覆盖。未编辑保存不会重写文件。
- 修改过的帧数组初始化内容会重新排版，原数组内部注释会随之替换；未修改数组和数组外代码保持原样。
  新增、禁用槽位或更新数字帧数时会重建 `programs` 初始化内容，并使用 `sizeof` 自动计算帧数。
- 支持当前 `static const struct kbd_macro_frame name[]` 数组及 `programs` 显式槽位格式；
  帧数组使用 `[]` 自动确定长度，槽位表长度必须是 `KBD_MACRO_SLOT_COUNT` 或 4；
  复杂 C 表达式、共享帧数组等不支持的格式会报错，避免猜测后覆盖源文件。
- 时间差是固件最小间隔，不保证主机恰好在对应毫秒收到事件；BLE 合并超过 6 个普通键会取消宏。
  详细执行时序见项目根目录的 `宏设计整改.md`。

## 保存与固件

- 仅替换 `key_table` 和 `knob_map` 内发生修改的键值，保留注释、换行、其余代码和显式数组长度。
- 支持当前工程两层、每层 85～88 项的常量/整数初始化格式；复杂 C 表达式会拒绝加载。
- 当前每层显式 85 项，末尾三个隐式零值不显示，也不会被填充或覆盖。
- 每次保存前，在源文件旁生成带时间戳的 `.bak` 备份，再通过临时文件替换原文件。
- 检测到外部修改时拒绝覆盖。可“重新加载”并选择不保存编辑区修改，再重新应用所需改键。
- 启动、切换层、点击按键均不会写文件。
- 默认编辑的是 `Keyboard-Config/keymap.c` 和 `Keyboard-Config/macro_config.c`。
  工程构建使用 `Lib/src/keymap.c` 和 `Lib/src/macro_config.c`。
  要让配置生效，需自行同步修改过的文件，再编译烧录。程序不会自动同步或烧录。
- 物理布局下标固定对应当前 PCB；不能通过本程序改变扫描顺序。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试通过临时文件验证键位、旋转、宏序列的读写、备份、外部修改保护、撤销和 GUI 回调，不修改实际配置文件。
这些测试不代表已经完成 Zephyr 固件构建、烧录或硬件时序验证。
